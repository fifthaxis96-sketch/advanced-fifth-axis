# Edit your search titles and descriptions

Open [content/seo.json in the GitHub editor](https://github.com/fifthaxis96-sketch/advanced-fifth-axis/edit/main/content/seo.json).

1. Find the page path. `/` is the English homepage; `/ar` is the Arabic homepage. Product and collection pages each have separate English and Arabic entries.
2. Change only the text inside `title` and `description`. Keep the page paths, quotes, commas and braces intact. Escape any quotation marks inside text as \\".
3. Click **Commit changes**. The production build reads this file and applies your text to the HTML title, meta description, Open Graph and Twitter metadata.
4. Check the [GitHub quality workflow](https://github.com/fifthaxis96-sketch/advanced-fifth-axis/actions) and the Cloudflare deployment check on the commit. When deployment succeeds, inspect the page source for the updated title and description.

Example:

```json
"/": {
  "title": "Foundation Drilling Tools Saudi Arabia | Advanced Fifth Axis",
  "description": "Explore foundation drilling tools, casing and wear parts from Advanced Fifth Axis in Jeddah. Contact our team for specifications and quotations."
}
```

Use an accurate, distinct title and description for each page, in the same language as its visible content. Avoid keyword lists and unverified claims. Roughly 50–60 title characters and 140–160 description characters can be useful editorial targets for English, but are not Google acceptance limits. Arabic display width differs. Google may rewrite titles and snippets to suit the search.

## Technical settings

| Field or setting | Purpose | Management |
| --- | --- | --- |
| Title and meta description | Describe the page and influence search appearance | Edit content/seo.json |
| Canonical URL | Identify the preferred URL | Generated by page metadata |
| English/Arabic hreflang | Link language counterparts | Generated in pages and sitemap |
| Robots directives | Permit crawling, indexing and previews | app/robots.ts and language layouts |
| Sitemap and product images | Help discover canonical pages and images | app/sitemap.ts |
| Organization, WebSite, Product, breadcrumbs | Explain factual entities and relationships | lib/organization.ts and page components |
| Image alt text and page headings | Describe visible content | Components and product content |
| Open Graph and Twitter metadata | Control social sharing previews | Synced with the editable SEO fields |

There is no mandatory set of meta fields that guarantees ranking. Google requires accessible working pages with indexable content. Titles and descriptions are recommended; meta keywords have no Google ranking or indexing effect. Verification tags are needed only when using the HTML-tag verification method; domain verification normally uses DNS.

Product pages are quotation-based. Do not invent prices, availability, reviews or ratings to satisfy rich-result requirements. Product markup alone does not guarantee Google Product rich-result eligibility.

## Search Console and Bing

Submit `https://advanced-fifthaxis.com/sitemap.xml` under **Sitemaps** in the verified property. Check the last read date, status and discovered pages. Use **URL Inspection** for the homepage, an English product and its Arabic counterpart; check live accessibility, indexing status and Google-selected canonical. Request indexing for important updated pages.

A successful sitemap fetch is not confirmation that every URL is indexed. GitHub and Cloudflare deployment checks do not provide private Search Console indexing data.

## AI discovery

The wildcard robots rule permits compliant crawlers, including search and AI crawlers. Cloudflare bot protection can still block requests independently; check account settings if a verified crawler is denied.

`/llms.txt` provides an optional factual directory for clients that support it. It is not a universal agent-discovery standard. Google AI search uses ordinary SEO eligibility and does not require an AI text file, special schema or agents file. An AGENTS.md file is for coding-agent instructions and is not a search-indexing requirement.
