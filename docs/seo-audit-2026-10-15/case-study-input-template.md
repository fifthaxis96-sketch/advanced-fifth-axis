# Evidence required before publishing a project case study

No new case study is published by this change. Existing gallery captions describe visible scenes and do not assert customer identity, location, supplied SKU or performance.

| Field | English publishing field | Arabic publishing field | Evidence needed |
| --- | --- | --- | --- |
| Permission | Photo and customer release | إذن نشر الصور واسم العميل | Rights holder's permission and allowed attribution; identify any redactions |
| Project identity | Approved project name/location | اسم المشروع والموقع المصرح بنشرهما | Owner/client confirmation; do not infer location from a photograph |
| Dates | Actual project/supply dates | تواريخ المشروع والتوريد الفعلية | Dated records; no invented publication/freshness dates |
| Scope | Actual supplied tool/component and configuration | الأداة أو المكون المورد فعليًا وتكوينه | Drawing/order/reference tying the supplied part to the project |
| Conditions | Confirmed application and ground conditions | الاستخدام وطبيعة الطبقات المؤكدان | Approved technical/geotechnical source |
| Result | Substantiated outcome | النتيجة المثبتة | Measured record and permission; omit results if unsupported |
| Testimonial | Approved quotation and attribution | إفادة معتمدة ونسبتها لصاحبها | Verbatim owner/customer approval; no invented review |
| Links | Relevant existing product/guide | المنتج أو الدليل المرتبط | Verify actual supplied product before using a case-study product link |

Suggested bilingual structure once evidence exists: project context / سياق المشروع; confirmed requirement / المتطلبات المؤكدة; supplied scope / نطاق التوريد; site photographs with factual captions / صور ميدانية وتعليقات واقعية; verified result when supported / نتيجة موثقة عند توفرها; relevant technical guide / دليل فني مرتبط. This is an unpublished editorial template, not evidence that these facts exist.
